# 💰 Montra Tracker

A personal finance tracker that brings income, expenses, budgets, and savings goals together in one organized and intuitive dashboard.

## ✨ Features

* **Income Tracking** — Add and manage income transactions.
* **Expense Tracking** — Record and organize expenses manually.
* **Categories** — Categorize transactions to better understand spending.
* **Financial Overview** — View income, expenses, and monthly budget in one place.
* **Monthly Tracking** — Navigate between months and review financial activity.
* **Savings Goals** — Create savings goals and track their progress.
* **Budget Management** — Set spending limits and monitor progress by category.
* **User Accounts** — Create an account and manage personal financial data.
* **Authentication** — Login and registration system.
* **Responsive** — Adapted for different screen sizes.
* **Manual Entries** — No bank connections or banking credentials required.

## 🛠️ Technologies

* **HTML5**
* **CSS3**
* **JavaScript**
* **SQL**
* **PostgreSQL**
* **Supabase**

## 🎨 Design

Montra follows a clean, modern editorial aesthetic focused on clarity and usability.

The interface combines expressive typography with structured layouts and financial cards, keeping important information easy to scan without overwhelming the user.

The design uses:

* **Fraunces** for headings
* **Inter** for interface and body text
* **IBM Plex Mono** for numerical and technical elements
* Responsive layouts
* Visual progress indicators
* Subtle transitions and animations
* Consistent spacing, typography, and component styling

## ♿ Accessibility

Accessibility was considered throughout the interface to make the application easier to navigate and understand.

* Semantic HTML elements
* Descriptive labels for form fields
* Accessible button and navigation elements
* `aria-label` attributes where additional context is needed
* `aria-live` regions for dynamic status messages
* Sufficient visual hierarchy and readable typography
* Responsive layouts for different screen sizes
